# Support

Use public GitHub Issues for this adapter for:

- plugin/command/runtime behavior defects,
- validation pipeline failures,
- documentation drift.

For security reports, use a private advisory at the repository security page.
Do **not** open public issue text for exploit details.

When filing an issue, include:

- operating system and shell,
- relevant `.opencode`/script configuration,
- commit SHA,
- sanitized output from `bash scripts/validate_config.sh` and `python3 scripts/validate_contract.py`,
- concise reproducible steps.
