### Fixed

- **P0-1 — `ry-flow-hooks.ts` hook contract.** `tool.execute.after` previously
  read the bash command from `output.args.command`. The
  `@opencode-ai/plugin@1.15.4` SDK contract places `args` on `input`, so the
